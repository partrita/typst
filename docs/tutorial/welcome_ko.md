# 튜토리얼
Typst 튜토리얼에 오신 것을 환영합니다! 이 튜토리얼에서는 Typst에서 문서를 작성하고 서식을 지정하는 방법을 배웁니다. 일상적인 작업부터 시작하여 점차 고급 기능을 소개합니다. 이 튜토리얼은 Typst, 다른 마크업 언어 또는 프로그래밍에 대한 사전 지식을 가정하지 않습니다. 텍스트 파일을 편집하는 방법을 알고 있다고 가정합니다.

가장 좋은 시작 방법은 Typst 앱에 무료로 가입하고 아래 단계를 따르는 것입니다. 이 앱은 즉각적인 미리보기, 구문 강조 표시 및 유용한 자동 완성을 제공합니다. 또는 [오픈 소스 CLI](https://github.com/typst/typst)를 사용하여 로컬 텍스트 편집기에서 따라 할 수 있습니다.

## Typst를 사용하는 경우 { #when-typst }
시작하기 전에 Typst가 무엇이며 언제 사용해야 하는지 확인해 보겠습니다. Typst는 문서 조판을 위한 마크업 언어입니다. 배우기 쉽고 빠르며 다재다능하도록 설계되었습니다. Typst는 마크업이 포함된 텍스트 파일을 가져와 PDF를 출력합니다.

Typst는 에세이, 기사, 과학 논문, 책, 보고서 및 숙제와 같은 모든 긴 형식의 텍스트를 작성하는 데 좋은 선택입니다. 또한 Typst는 수학, 물리학 및 공학 분야의 논문과 같이 수학적 표기법이 포함된 모든 문서에 매우 적합합니다. 마지막으로 강력한 스타일링 및 자동화 기능으로 인해 책 시리즈와 같이 공통 스타일을 공유하는 모든 문서 세트에 탁월한 선택입니다.

## 배우게 될 내용 { #learnings }
이 튜토리얼은 4개의 장으로 구성되어 있습니다. 각 장은 이전 장을 기반으로 합니다. 각 장에서 배우게 될 내용은 다음과 같습니다.

1. [Typst로 글쓰기:]($tutorial/writing-in-typst) 텍스트를 작성하고 이미지, 방정식 및 기타 요소를 삽입하는 방법을 배웁니다.
2. [서식 지정:]($tutorial/formatting) 글꼴 크기, 제목 스타일 등을 포함하여 문서 서식을 조정하는 방법을 배웁니다.
3. [고급 스타일링:]($tutorial/advanced-styling) 저자 목록 및 런인 제목과 같은 조판 기능이 있는 과학 논문을 위한 복잡한 페이지 레이아웃을 만듭니다.
4. [템플릿 만들기:]($tutorial/making-a-template) 이전 장에서 만든 논문에서 재사용 가능한 템플릿을 만듭니다.

Typst를 즐기시기 바랍니다!
