# Typst로 글쓰기
시작해 봅시다! 대학교에서 기술 보고서를 작성하라는 과제를 받았다고 가정해 보겠습니다. 보고서에는 산문, 수학, 제목, 그림이 포함될 것입니다. 시작하려면 Typst 앱에서 새 프로젝트를 만듭니다. 그러면 편집기로 이동하여 두 개의 패널이 표시됩니다. 문서를 작성하는 소스 패널과 렌더링된 문서를 볼 수 있는 미리보기 패널입니다.

![Typst 앱 스크린샷](1-writing-app.png)

보고서에 대한 좋은 아이디어가 이미 있습니다. 그럼 서론부터 작성해 봅시다. 편집기 패널에 텍스트를 입력합니다. 텍스트가 미리보기 페이지에 즉시 나타나는 것을 알 수 있습니다.

```example
이 보고서에서는 빙하의 유체 역학에 영향을 미치는 다양한 요인과 이러한 요인이 이러한 자연 구조물의 형성과 거동에 어떻게 기여하는지 살펴볼 것입니다.
```

_이 튜토리얼 전체에서 이와 같은 코드 예제를 보여줄 것입니다. 앱에서와 마찬가지로 첫 번째 패널에는 마크업이 포함되어 있고 두 번째 패널에는 미리보기가 표시됩니다. 무슨 일이 일어나고 있는지 볼 수 있도록 예제를 맞추기 위해 페이지를 축소했습니다._

다음 단계는 제목을 추가하고 일부 텍스트를 강조하는 것입니다. Typst는 가장 일반적인 서식 작업에 간단한 마크업을 사용합니다. 제목을 추가하려면 `=` 문자를 입력하고 텍스트를 기울임꼴로 강조하려면 `[_밑줄_]`로 묶습니다.

```example
= 서론
이 보고서에서는 _유체 역학_에 영향을 미치는 다양한 요인과 이러한 요인이 이러한 자연 구조물의 형성과 거동에 어떻게 기여하는지 살펴볼 것입니다.
```

쉬웠죠! 새 단락을 추가하려면 텍스트 두 줄 사이에 빈 줄을 추가하기만 하면 됩니다. 해당 단락에 부제목이 필요한 경우 `=` 대신 `==`를 입력하여 만듭니다. `=` 문자의 수는 제목의 중첩 수준을 결정합니다.

이제 빙하 역학에 영향을 미치는 몇 가지 상황을 나열하려고 합니다. 그렇게 하려면 번호 매기기 목록을 사용합니다. 목록의 각 항목에 대해 줄 시작 부분에 `+` 문자를 입력합니다. Typst가 항목에 자동으로 번호를 매깁니다.

```example
+ 기후
+ 지형
+ 지질학
```

글머리 기호 목록을 추가하려면 `+` 문자 대신 `-` 문자를 사용합니다. 목록을 중첩할 수도 있습니다. 예를 들어 위 목록의 첫 번째 항목에 하위 목록을 들여쓰기하여 추가할 수 있습니다.

```example
+ 기후
  - 온도
  - 강수량
+ 지형
+ 지질학
```

## 그림 추가 { #figure }
보고서에 그림이 있으면 좋을 것 같습니다. 하나 추가해 봅시다. Typst는 PNG, JPEG, GIF, SVG 및 WebP 형식의 이미지를 지원합니다. 프로젝트에 이미지 파일을 추가하려면 먼저 왼쪽 사이드바에서 상자 아이콘을 클릭하여 _파일 패널_을 엽니다. 여기에서 프로젝트의 모든 파일 목록을 볼 수 있습니다. 현재는 하나만 있습니다. 작성 중인 기본 Typst 파일입니다. 다른 파일을 업로드하려면 오른쪽 상단의 화살표가 있는 버튼을 클릭합니다. 그러면 업로드 대화 상자가 열리고 컴퓨터에서 업로드할 파일을 선택할 수 있습니다. 보고서용 이미지 파일을 선택합니다.

![업로드 대화 상자](1-writing-upload.png)

특정 기호(_마크업_이라고 함)가 Typst에서 특정 의미를 갖는다는 것을 이전에 보았습니다. 각각 제목, 목록 및 강조된 텍스트를 만들기 위해 `=`, `-`, `+` 및 `_`를 사용할 수 있습니다. 그러나 문서에 삽입하려는 모든 것에 대해 특수 기호를 사용하는 것은 곧 암호화되고 다루기 어려워질 것입니다. 이러한 이유로 Typst는 가장 일반적인 항목에 대해서만 마크업 기호를 예약합니다. 다른 모든 것은 _함수_를 사용하여 삽입됩니다. 이미지가 페이지에 표시되도록 하려면 Typst의 [`image`] 함수를 사용합니다.

```example
#image("glacier.jpg")
```

일반적으로 함수는 일련의 _인수_에 대한 일부 출력을 생성합니다. 마크업 내에서 함수를 _호출_하면 인수를 제공하고 Typst는 결과(함수의 _반환 값_)를 문서에 삽입합니다. 이 경우 `image` 함수는 하나의 인수를 사용합니다. 이미지 파일의 경로입니다. 마크업에서 함수를 호출하려면 먼저 `#` 문자를 입력하고 바로 뒤에 함수 이름을 입력합니다. 그런 다음 인수를 괄호로 묶습니다. Typst는 인수 목록 내에서 다양한 데이터 유형을 인식합니다. 파일 경로는 짧은 [텍스트 문자열]($str)이므로 큰따옴표로 묶어야 합니다.

삽입된 이미지는 페이지의 전체 너비를 사용합니다. 이를 변경하려면 `image` 함수에 `width` 인수를 전달합니다. 이것은 _명명된_ 인수이므로 `name: value` 쌍으로 지정됩니다. 여러 인수가 있는 경우 쉼표로 구분되므로 먼저 경로 뒤에 쉼표를 넣어야 합니다.

```example
#image("glacier.jpg", width: 70%)
```

`width` 인수는 [상대 길이]($relative)입니다. 이 경우 백분율을 지정하여 이미지가 페이지 너비의 `{70%}`를 차지하도록 결정했습니다. `{1cm}` 또는 `{0.7in}`와 같은 절대값을 지정할 수도 있습니다.

텍스트와 마찬가지로 이미지는 이제 기본적으로 페이지 왼쪽에 정렬됩니다. 또한 캡션이 없습니다. [figure] 함수를 사용하여 이를 수정해 봅시다. 이 함수는 그림의 내용을 위치 인수로 사용하고 선택적 캡션을 명명된 인수로 사용합니다.

`figure` 함수의 인수 목록 내에서 Typst는 이미 코드 모드입니다. 즉, 이제 이미지 함수 호출 전에 해시를 제거해야 합니다. 해시는 마크업에서 직접적으로만 필요합니다(텍스트와 함수 호출을 구분하기 위해).

캡션은 임의의 마크업으로 구성됩니다. 함수에 마크업을 제공하려면 대괄호로 묶습니다. 이 구성을 _콘텐츠 블록_이라고 합니다.

```example
#figure(
  image("glacier.jpg", width: 70%),
  caption: [
    _빙하_는 지구 기후 시스템의 중요한 부분을 형성합니다.
  ],
)
```

보고서를 계속 작성하고 이제 그림을 참조하려고 합니다. 그렇게 하려면 먼저 그림에 레이블을 첨부합니다. 레이블은 문서의 요소를 고유하게 식별합니다. 꺾쇠괄호 안에 일부 이름을 묶어 그림 뒤에 추가합니다. 그런 다음 `[@]` 기호와 해당 이름을 작성하여 텍스트에서 그림을 참조할 수 있습니다. 제목과 방정식에도 레이블을 지정하여 참조할 수 있도록 할 수 있습니다.

```example
@glaciers에 표시된 것과 같은 빙하는 우리가 곧 조치를 취하지 않으면 더 이상 존재하지 않을 것입니다!

#figure(
  image("glacier.jpg", width: 70%),
  caption: [
    _빙하_는 지구 기후 시스템의 중요한 부분을 형성합니다.
  ],
) <glaciers>
```

<div class="info-box">

지금까지 함수에 콘텐츠 블록(대괄호 안의 마크업)과 문자열(큰따옴표 안의 텍스트)을 전달했습니다. 둘 다 텍스트를 포함하는 것 같습니다. 차이점은 무엇입니까?

콘텐츠 블록에는 텍스트뿐만 아니라 다른 종류의 마크업, 함수 호출 등이 포함될 수 있지만 문자열은 실제로 _문자 시퀀스_일 뿐 다른 것은 아닙니다.

예를 들어 image 함수는 이미지 파일의 경로를 예상합니다.
이미지의 경로 매개변수로 예를 들어 텍스트 단락이나 다른 이미지를 전달하는 것은 의미가 없습니다. 그렇기 때문에 여기서는 문자열만 허용됩니다.
반대로 텍스트는 유효한 종류의 콘텐츠이기 때문에 콘텐츠가 예상되는 모든 곳에서 문자열이 작동합니다.
</div>

## 참고 문헌 추가 { #bibliography }
보고서를 작성하면서 일부 주장을 뒷받침해야 합니다. [`bibliography`] 함수를 사용하여 문서에 참고 문헌을 추가할 수 있습니다. 이 함수는 참고 문헌 파일의 경로를 예상합니다.

Typst의 기본 참고 문헌 형식은 [Hayagriva](https://github.com/typst/hayagriva/blob/main/docs/file-format.md)이지만 호환성을 위해 BibLaTeX 파일을 사용할 수도 있습니다. 반 친구가 이미 문헌 조사를 마치고 `.bib` 파일을 보내주었으므로 그것을 사용할 것입니다. 파일 패널을 통해 파일을 업로드하여 Typst에서 액세스합니다.

문서에 참고 문헌이 포함되면 인용을 시작할 수 있습니다.
인용은 레이블 참조와 동일한 구문을 사용합니다.
처음으로 출처를 인용하면 문서의 참고 문헌 섹션에 나타납니다. Typst는 다양한 인용 및 참고 문헌 스타일을 지원합니다.
자세한 내용은 [참고 자료]($bibliography.style)를 참조하십시오.

```example
= 방법
@glacier-melt에 확립된 빙하 용융 모델을 따릅니다.

#bibliography("works.bib")
```

## 수학
방법 섹션을 구체화한 후 문서의 핵심인 방정식으로 넘어갑니다. Typst에는 수학 조판 기능이 내장되어 있으며 자체 수학 표기법을 사용합니다. 간단한 방정식부터 시작하겠습니다. Typst가 수학 표현식을 예상해야 함을 알리도록 `[$]` 기호로 묶습니다.

```example
방정식 $Q = rho A v + C$는 빙하 유량을 정의합니다.
```

방정식은 주변 텍스트와 같은 줄에 인라인으로 조판됩니다. 대신 자체 줄에 표시하려면 시작과 끝에 단일 공백을 삽입해야 합니다.

```example
빙하의 유량은 다음 방정식으로 정의됩니다.

$ Q = rho A v + C $
```

Typst는 단일 문자 `Q`, `A`, `v` 및 `C`를 있는 그대로 표시하는 반면 `rho`는 그리스 문자로 변환했습니다. 수학 모드는 항상 단일 문자를 있는 그대로 표시합니다. 그러나 여러 문자는 기호, 변수 또는 함수 이름으로 해석됩니다. 단일 문자 사이에 곱셈을 암시하려면 문자 사이에 공백을 넣습니다.

여러 문자로 구성된 변수를 사용하려면 따옴표로 묶을 수 있습니다.

```example
빙하의 유량은 다음 방정식으로 주어집니다.

$ Q = rho A v + "시간 오프셋" $
```

논문에는 합계 공식도 필요합니다. `sum` 기호를 사용한 다음 아래 첨자와 위 첨자에 합계 범위를 지정할 수 있습니다.

```example
빙하 흐름에 의한 총 변위 토양:

$ 7.32 beta +
  sum_(i=0)^nabla Q_i / 2 $
```

기호나 변수에 아래 첨자를 추가하려면 `_` 문자를 입력한 다음 아래 첨자를 입력합니다. 마찬가지로 위 첨자에는 `^` 문자를 사용합니다. 아래 첨자나 위 첨자가 여러 항목으로 구성된 경우 둥근 괄호로 묶어야 합니다.

위의 예는 또한 분수를 삽입하는 방법을 보여주었습니다. 분자와 분모 사이에 `/` 문자를 넣기만 하면 Typst가 자동으로 분수로 변환합니다. 괄호는 스마트하게 확인되므로 계산기에 입력하는 것처럼 표현식을 입력하면 Typst가 괄호로 묶인 하위 표현식을 적절한 표기법으로 바꿉니다.

```example
빙하 흐름에 의한 총 변위 토양:

$ 7.32 beta +
  sum_(i=0)^nabla
    (Q_i (a_i - epsilon)) / 2 $
```

모든 수학 구성 요소에 특수 구문이 있는 것은 아닙니다. 대신 이전에 본 `image` 함수와 마찬가지로 함수를 사용합니다. 예를 들어 열 벡터를 삽입하려면 [`vec`]($math.vec) 함수를 사용할 수 있습니다. 수학 모드 내에서 함수 호출은 `#` 문자로 시작할 필요가 없습니다.

```example
$ v := vec(x_1, x_2, x_3) $
```

일부 함수는 수학 모드 내에서만 사용할 수 있습니다. 예를 들어 [`cal`]($math.cal) 함수는 집합에 일반적으로 사용되는 필기체 문자를 조판하는 데 사용됩니다. [참고 자료의 수학 섹션]($category/math)에는 수학 모드에서 사용할 수 있는 모든 함수 목록이 나와 있습니다.

한 가지 더: 화살표와 같은 많은 기호에는 다양한 변형이 있습니다. 기호 이름에 점과 수정자 이름을 추가하여 이러한 변형 중에서 선택할 수 있습니다.

```example
$ a arrow.squiggly b $
```

이 표기법은 마크업 모드에서도 사용할 수 있지만 기호 이름 앞에는 `#sym.`이 와야 합니다. 사용 가능한 모든 기호 목록은 [기호 섹션]($category/symbols/sym)을 참조하십시오.

## 검토
이제 Typst에서 기본 문서를 작성하는 방법을 보았습니다. 텍스트를 강조하고, 목록을 작성하고, 이미지를 삽입하고, 콘텐츠를 정렬하고, 수학 표현식을 조판하는 방법을 배웠습니다. Typst의 함수에 대해서도 배웠습니다. Typst를 사용하면 [표]($table), [도형]($category/visualize) 및 [코드 블록]($raw)과 같이 문서에 삽입할 수 있는 더 많은 종류의 콘텐츠가 있습니다. [참고 자료]를 자세히 살펴보면 이러한 기능 및 기타 기능에 대해 자세히 알아볼 수 있습니다.

지금은 보고서 작성을 완료했습니다. 오른쪽 상단의 다운로드 버튼을 클릭하여 이미 PDF를 저장했습니다. 그러나 보고서가 좀 더 평범해 보이지 않도록 할 수 있다고 생각합니다. 다음 섹션에서는 문서의 모양을 사용자 지정하는 방법을 알아봅니다.
