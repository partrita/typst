# 서식 지정
지금까지 텍스트, 몇 가지 방정식 및 이미지가 포함된 보고서를 작성했습니다.
그러나 여전히 매우 평범해 보입니다. 조교는 아직
새로운 조판 시스템을 사용하고 있다는 사실을 모르고 있으며, 보고서가
다른 학생들의 제출물과 어울리기를 원합니다. 이 장에서는 Typst의 스타일링 시스템을 사용하여 보고서 서식을 지정하는 방법을 살펴보겠습니다.

## 설정 규칙
이전 장에서 보았듯이 Typst에는 콘텐츠를 _삽입_하는 함수(예: [`image`] 함수)와 인수로 받은 콘텐츠를 _조작_하는 함수(예: [`align`] 함수)가 있습니다. 예를 들어 글꼴을 변경하고 싶을 때 가장 먼저 떠오르는 생각은 해당 작업을 수행하는 함수를 찾아 전체 문서를 해당 함수로 래핑하는 것일 수 있습니다.

```example
#text(font: "New Computer Modern")[
  = 배경
  빙하의 경우 유체 역학 원리를 사용하여 온도, 압력 및 기타 유체(예: 물)의 존재와 같은 요인이 얼음의 움직임과 거동에 어떤 영향을 미치는지 이해할 수 있습니다.
]
```

잠깐, 함수의 모든 인수를 괄호 안에 지정해야 하지 않나요? 왜 괄호 _뒤에_ 내용이 있는 두 번째 대괄호 세트가 있나요?
답은 함수에 콘텐츠를 전달하는 것이 Typst에서 매우 일반적인 작업이기 때문에 특별한 구문이 있다는 것입니다. 인수 목록 안에 콘텐츠를 넣는 대신 일반 인수 바로 뒤에 대괄호로 작성하여 구두점을 절약할 수 있습니다.

위에서 본 것처럼 작동합니다. [`text`] 함수를 사용하면 그 안의 모든 텍스트에 대한 글꼴을 조정할 수 있습니다. 그러나 문서를 수많은 함수로 래핑하고 스타일을 선택적으로 현장에서 적용하는 것은 금방 번거로워질 수 있습니다.

다행히 Typst에는 더 우아한 솔루션이 있습니다. _설정 규칙_을 사용하면 특정 종류의 콘텐츠의 모든 발생에 스타일 속성을 적용할 수 있습니다. `{set}` 키워드를 입력한 다음 속성을 설정하려는 함수의 이름과 괄호 안의 인수 목록을 입력하여 설정 규칙을 작성합니다.

```example
#set text(
  font: "New Computer Modern"
)

= 배경
빙하의 경우 유체 역학 원리를 사용하여 온도, 압력 및 기타 유체(예: 물)의 존재와 같은 요인이 얼음의 움직임과 거동에 어떤 영향을 미치는지 이해할 수 있습니다.
```

<div class="info-box">

여기서 무슨 일이 일어나고 있는지 기술적인 용어로 알고 싶으신가요?

설정 규칙은 해당 함수의 모든 향후 사용에 대해 함수의 일부 매개변수에 대한 기본값을 설정하는 것으로 개념화할 수 있습니다.
</div>

## 자동 완성 패널 { #autocomplete }
앱에서 몇 가지 작업을 따라 해보고 시도해 보았다면 `#` 문자를 입력할 때마다 사용 가능한 함수를 보여주는 패널이 나타나고 인수 목록 내에서는 사용 가능한 매개변수가 표시되는 것을 눈치챘을 것입니다.
이것이 자동 완성 패널입니다. 문서를 작성하는 동안 매우 유용할 수 있습니다. Return 키를 눌러 제안을 적용하거나 화살표 키를 사용하여 원하는 완성으로 이동할 수 있습니다. Escape 키를 눌러 패널을 닫고 `#`을 입력하거나 <kbd>Ctrl</kbd> + <kbd>Space</kbd>를 눌러 다시 열 수 있습니다. 자동 완성 패널을 사용하여 함수에 대한 올바른 인수를 찾으십시오. 대부분의 제안에는 수행하는 작업에 대한 간단한 설명이 함께 제공됩니다.

## 페이지 설정 { #page-setup }
설정 규칙으로 돌아가서 규칙을 작성할 때 스타일을 지정하려는 요소 유형에 따라 함수를 선택합니다. 다음은 설정 규칙에서 일반적으로 사용되는 몇 가지 함수 목록입니다.

- [`text`] 글꼴 모음, 크기, 색상 및 기타 텍스트 속성 설정
- [`page`] 페이지 크기, 여백, 머리글, 열 활성화 및 바닥글 설정
- [`par`] 단락 정렬, 줄 간격 설정 등
- [`heading`] 제목 모양 설정 및 번호 매기기 활성화
- [`document`] 제목 및 저자와 같은 PDF 출력에 포함된 메타데이터 설정

모든 함수 매개변수를 설정할 수 있는 것은 아닙니다. 일반적으로 함수에 _무엇을_ 해야 하는지 알려주는 매개변수가 아니라 _어떻게_ 해야 하는지 알려주는 매개변수만 설정할 수 있습니다. 함수 참조 페이지에는 설정 가능한 매개변수가 표시됩니다.

문서에 몇 가지 스타일을 더 추가해 봅시다. 더 큰 여백과 세리프 글꼴을 원합니다. 예시를 위해 다른 페이지 크기도 설정하겠습니다.

```example
#set page(
  paper: "a6",
  margin: (x: 1.8cm, y: 1.5cm),
)
#set text(
  font: "New Computer Modern",
  size: 10pt
)
#set par(
  justify: true,
  leading: 0.52em,
)

= 서론
이 보고서에서는 빙하의 유체 역학에 영향을 미치는 다양한 요인과 이러한 요인이 이러한 자연 구조물의 형성과 거동에 어떻게 기여하는지 살펴볼 것입니다.

>>> 빙하 변위는 다음과 같은 여러 요인의 영향을 받습니다.
>>> + 기후
>>> + 지형
>>> + 지질학
>>>
>>> 이 보고서는 빙하 변위 및 역학의 물리적 모델을 제시하고 이러한 요인이 거대한 얼음 덩어리의 움직임에 미치는 영향을 탐구합니다.
<<< ...

#align(center + bottom)[
  #image("glacier.jpg", width: 70%)

  *빙하는 지구 기후 시스템의 중요한 부분을 형성합니다.*
]
```

여기에는 몇 가지 주목할 점이 있습니다.

첫 번째는 [`page`] 설정 규칙입니다. 페이지 크기와 페이지 여백이라는 두 가지 인수를 받습니다. 페이지 크기는 문자열입니다. Typst는 [많은 표준 페이지 크기]($page.paper)를 허용하지만 사용자 지정 페이지 크기를 지정할 수도 있습니다. 여백은 [사전]($dictionary)으로 지정됩니다. 사전은 키-값 쌍의 모음입니다. 이 경우 키는 `x`와 `y`이고 값은 각각 가로 및 세로 여백입니다. `{left}`, `{right}`, `{top}` 및 `{bottom}` 키가 있는 사전을 전달하여 각 면에 대해 별도의 여백을 지정할 수도 있습니다.

다음은 [`text`] 설정 규칙입니다. 여기서는 글꼴 크기를 `{10pt}`로 설정하고 글꼴 모음을 `{"New Computer Modern"}`으로 설정합니다. Typst 앱에는 문서에 사용할 수 있는 많은 글꼴이 함께 제공됩니다. 텍스트 함수의 인수 목록에 있으면 자동 완성 패널에서 사용 가능한 글꼴을 찾을 수 있습니다.

줄 사이의 간격(행간이라고도 함)도 설정했습니다. [길이] 값으로 지정되며 `em` 단위를 사용하여 글꼴 크기에 상대적인 행간을 지정했습니다. `{1em}`은 현재 글꼴 크기(기본값은 `{11pt}`)와 같습니다.

마지막으로 가운데 정렬에 세로 정렬을 추가하여 이미지를 아래쪽으로 정렬했습니다. 세로 및 가로 정렬은 `{+}` 연산자와 결합하여 2D 정렬을 생성할 수 있습니다.

## 약간의 세련됨 { #sophistication }
문서를 더 명확하게 구성하기 위해 이제 제목에 번호를 매기려고 합니다. [`heading`] 함수의 `numbering` 매개변수를 설정하여 이 작업을 수행할 수 있습니다.

```example
>>> #set text(font: "New Computer Modern")
#set heading(numbering: "1.")

= 서론
#lorem(10)

== 배경
#lorem(12)

== 방법
#lorem(15)
```

번호 매기기 매개변수로 문자열 `{"1."}`을 지정했습니다. 이렇게 하면 Typst에 아라비아 숫자로 제목 번호를 매기고 각 수준의 숫자 사이에 점을 넣도록 지시합니다. 제목에 [문자, 로마 숫자 및 기호]($numbering)를 사용할 수도 있습니다.

```example
>>> #set text(font: "New Computer Modern")
#set heading(numbering: "1.a")

= 서론
#lorem(10)

== 배경
#lorem(12)

== 방법
#lorem(15)
```

이 예에서는 또한 [`lorem`] 함수를 사용하여 일부 자리 표시자 텍스트를 생성합니다. 이 함수는 숫자를 인수로 사용하고 해당 단어 수만큼의 _Lorem Ipsum_ 텍스트를 생성합니다.

<div class="info-box">

해당 함수로 생성되지 않은 경우에도 제목 및 텍스트 설정 규칙이 모든 텍스트 및 제목에 적용되는 이유가 궁금하셨나요?

Typst는 `[= 결론]`을 작성할 때마다 내부적으로 `heading` 함수를 호출합니다. 실제로 함수 호출 `[#heading[결론]]`은 위의 제목 마크업과 동일합니다. 다른 마크업 요소도 유사하게 작동하며 해당 함수 호출에 대한 _구문 설탕_일 뿐입니다.
</div>

## 표시 규칙
이미 이 결과에 상당히 만족합니다. 그러나 마지막으로 한 가지 수정해야 할 사항이 있습니다. 작성 중인 보고서는 더 큰 프로젝트를 위한 것이며 해당 프로젝트의 이름은 산문에서도 항상 로고와 함께 표시되어야 합니다.

옵션을 고려합니다. 검색 및 바꾸기를 사용하여 로고의 모든 인스턴스 앞에 `[#image("logo.svg")]` 호출을 추가할 수 있습니다. 매우 지루하게 들립니다. 대신 로고와 이미지를 항상 생성하는 [사용자 지정 함수를 정의]($function/#defining-functions)할 수도 있습니다. 그러나 훨씬 더 쉬운 방법이 있습니다.

표시 규칙을 사용하면 Typst가 특정 요소를 표시하는 방식을 재정의할 수 있습니다. Typst가 다르게 표시해야 하는 요소와 모양을 지정합니다. 표시 규칙은 텍스트 인스턴스, 많은 함수, 심지어 전체 문서에도 적용할 수 있습니다.

```example
#show "ArtosFlow": name => box[
  #box(image(
    "logo.svg",
    height: 0.7em,
  ))
  #name
]

이 보고서는 ArtosFlow 프로젝트에 포함되어 있습니다. ArtosFlow는 Artos Institute의 프로젝트입니다.
```

이 예에는 새로운 구문이 많이 있습니다. `{show}` 키워드를 작성하고 그 뒤에 다르게 표시하려는 텍스트 문자열과 콜론을 작성합니다. 그런 다음 표시할 내용을 인수로 사용하는 함수를 작성합니다. 여기서는 해당 인수를 `name`이라고 불렀습니다. 이제 함수 본문에서 `name` 변수를 사용하여 ArtosFlow 이름을 인쇄할 수 있습니다. 표시 규칙은 이름 앞에 로고 이미지를 추가하고 결과를 상자에 넣어 로고와 이름 사이에 줄 바꿈이 발생하지 않도록 합니다. 이미지는 또한 상자 안에 넣어 자체 단락에 나타나지 않도록 합니다.

첫 번째 상자 함수와 이미지 함수에 대한 호출은 마크업에 직접 포함되지 않았기 때문에 선행 `#`이 필요하지 않았습니다. Typst가 마크업 대신 코드를 예상할 때 함수, 키워드 및 변수에 액세스하는 데 선행 `#`이 필요하지 않습니다. 이는 매개변수 목록, 함수 정의 및 [코드 블록]($scripting)에서 관찰할 수 있습니다.

## 검토
이제 Typst 문서에 기본 서식을 적용하는 방법을 알게 되었습니다. 설정 규칙을 사용하여 글꼴을 설정하고, 단락을 정렬하고, 페이지 크기를 변경하고, 제목에 번호를 매기는 방법을 배웠습니다. 또한 기본 표시 규칙을 사용하여 문서 전체에서 텍스트가 표시되는 방식을 변경하는 방법도 배웠습니다.
