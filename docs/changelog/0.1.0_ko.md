# 버전 0.1.0 (2023년 4월 4일)

## 주요 변경 사항
- CLI를 사용할 때 이제 하위 명령을 사용해야 합니다.
  - PDF를 만들려면 `typst compile file.typ` 또는 `typst c file.typ`
  - 컴파일하고 감시하려면 `typst watch file.typ` 또는 `typst w file.typ`
  - 모든 글꼴을 나열하려면 `typst fonts`
- 수동 카운터가 이제 0부터 시작합니다. 자세한 내용은 [$counter]의 "단계별 진행 방법" 섹션을 참조하세요.
- [$bibliography.style] `{"author-date"}` 및 `{"author-title"}`이 `{"chicago-author-date"}` 및 `{"chicago-author-title"}`로 이름이 변경되었습니다.

## 그림 개선 사항
- 그림이 이제 내용을 자동으로 감지하고 동작을 조정합니다. 예를 들어 표가 포함된 그림에는 자동으로 "표 X"라는 접두사가 붙고 별도의 카운터가 있습니다.
- 그림의 보충 자료(예: "그림" 또는 "표")를 이제 사용자 지정할 수 있습니다.
- 또한 표시 규칙이 자동으로 확인된 종류, 보충 자료 및 카운터에 대한 액세스를 제공하므로 이제 그림을 완전히 사용자 지정할 수 있습니다.

## 참고 문헌 개선 사항
- [`bibliography`]가 이제 여러 참고 문헌 경로(배열 형식)도 허용합니다.
- BibLaTeX 파일 구문 분석이 이제 더 허용적으로 변경되었습니다(숫자가 아닌 판, 페이지, 볼륨, 날짜 및 Jabref 스타일 주석 허용, 약어 구문 분석 수정).
- 레이블과 참조는 이제 마지막을 제외하고 `:` 및 `.`을 포함할 수 있습니다.
- APA 참고 문헌 순서가 수정되었습니다.

## 그리기 추가 사항
- 다각형을 그리기 위한 [`polygon`] 함수가 추가되었습니다.
- [상자]($box.clip) 및 [블록]($block.clip)에서 클리핑 지원이 추가되었습니다.

## 명령줄 인터페이스
- 이제 오류가 있으면 0이 아닌 상태 코드로 반환합니다.
- 이제 현재 디렉터리 대신 루트 디렉터리를 감시합니다.
- 이제 기본적으로 입력 파일 옆에 PDF 파일을 배치합니다.
- 이제 더 많은 종류의 입력 파일(예: `/dev/stdin`)을 허용합니다.
- PDF를 직접 열 수 있도록 `--open` 플래그가 추가되었습니다.

## 기타 개선 사항
- YAML 파일에서 데이터를 로드하는 [`yaml`] 함수가 추가되었습니다.
- 몇 가지 추가 언어(IT, RU, ZH, FR, PT)에 대한 기본 i18n이 추가되었습니다.
- 히브리어에 대한 번호 매기기 지원이 추가되었습니다.
- 밑수가 2, 8, 16인 [정수]($int) 지원이 추가되었습니다.
- 이중 대괄호 및 라플라스 연산자에 대한 기호가 추가되었습니다.
- [`link`] 함수가 이제 [레이블]($label)을 허용합니다.
- 링크 구문이 이제 더 많은 문자를 허용합니다.
- 일본어 및 중국어 텍스트의 정렬이 개선되었습니다.
- 계산 함수가 실수 아닌 결과에 대해 더 일관되게 동작합니다.
- 사용되지 않는 꺾쇠괄호가 대체되었습니다.
- 최대 함수 호출 깊이가 256에서 64로 줄었습니다.
- 단락이 스타일이 지정된 텍스트로 시작할 때 [`first-line-indent`]($par.first-line-indent)가 적용되지 않는 문제가 수정되었습니다.
- 방정식에서 단항 연산자의 불필요한 공백이 수정되었습니다.
- `{block(above: 1cm, below: 1cm, ..)}`와 같은 블록 간격이 수정되었습니다.
- 수학에서 텍스트 연산자의 스타일 지정이 수정되었습니다.
- 단일 백틱이 있는 원시 블록에서 언어 태그의 잘못된 구문 분석이 수정되었습니다.
- 카운터 및 상태 표시에 관련된 버그가 수정되었습니다.
- 페이지 카운터와 관련된 충돌이 수정되었습니다.
- 인수가 없이 [`symbol`] 함수가 호출될 때 발생하는 충돌이 수정되었습니다.
- 참고 문헌 생성 시 충돌이 수정되었습니다.
- 특정 콘텐츠 요소의 레이블에 대한 액세스가 수정되었습니다.
- CSV 구문 분석에 대한 오류 메시지의 줄 번호가 수정되었습니다.
- 특정 마크업 요소 뒤의 잘못된 자동 완성이 수정되었습니다.
